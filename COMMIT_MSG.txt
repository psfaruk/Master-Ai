history tab: revamp IA — Overall Win Rate headline + per-subset pair list + cross-linking

The user's complaint (Bengali):
  "এই অ্যাপ এ সিগন্যাল হিস্টোরি নিয়ে আমি সেটিসফাই না। যেমন এখন সব
   এলোমেলো লাগে। কোনো কিছু গোছানো নাই। হিস্টোরি ট্যাব ওপেন করলেই ফোল্ডার
   গুলো দেখা যাবে। Over all win rate, সেটার উপড়ে ক্লিক করলে বাকি তিনটি
   অ্যাপের overall win rate দেখা যাবে — অ্যাপ 1 অ্যাপ 2 অ্যাপ 3, তারপরও
   এটাও থাকবে app 1+2, 1+3, 2+3। তারপর ওই ট্যাব গুলো উপরে প্রত্যেক
   পেয়ারে কতগুলো সিগন্যাল, সিগন্যাল হিস্টোরি, প্রত্যেক পেয়ারের win rate
   দেখা যাবে। মানে বিষয় টি হলো প্রত্যেকটি বিষয় লিংক উইথ থাকবে।"

Translation: the History tab felt disorganized; the user wants the History
landing to show folders, an "Overall Win Rate" headline that on tap reveals
the win rate of App 1 / App 2 / App 3 / 1+2 / 1+3 / 2+3 / all-3, and per-
pair signal count + history + win rate on the per-subset tabs — all cross-
linked.

WHAT CHANGED

1. New History tab landing — "Overall Win Rate" headline folder (full-
   width, emerald-tinted) sits FIRST above the 4 existing folders. It
   answers the most important question: of App 1, App 2, App 3, and every
   combination, who wins most?

2. New "Overall Win Rate" sub-tab — 7-card grid (App 1, App 2, App 3,
   1+2, 1+3, 2+3, All 3). Each card shows:
     - global win rate (large, color-coded 60%/45%)
     - signal count (total signals across all pairs in that subset)
     - W/L + draw breakdown
     - "Best pair" line from the leaders leaderboard
   Tapping a card drills into the per-subset pair list.

3. New "Per-Subset Pair List" sub-tab — table of EVERY pair that has
   signals in ONE app subset, with:
     - ★ favorite toggle
     - Pair name (tap → per-pair drawer)
     - category
     - signal count in this subset
     - W/L
     - win rate (color-coded)
     - "History" button → per-pair drawer with that subset chip
       pre-selected on the Signal History table

4. Cross-linking — every relevant stat now navigates:
     - Backtest → "Win rate by app pair (global)" cards → per-subset pair
       list (same destination as the Overall cards)
     - Per-Pair Stats → app1+app2 / app1+app3 / app2+app3 / all-3 cells →
       per-pair drawer with subset chip pre-selected
     - App Pair Leaders → top-pair row → per-pair drawer
     - Per-subset pair list → row tap → drawer; "History" button →
       drawer with subset pre-filtered
     - Per-pair drawer → subset chip → re-filters Signal History table
       in-place (no extra fetch)

5. New backend endpoint — GET /api/app-pair/{subset}/pairs returns every
   pair that has signals for ONE app subset (no top-N cap, no
   LEADERBOARD_MIN_GRADED gate — every pair with ≥1 signal), with per-
   pair signal count, W/L, win rate, call/put breakdown, plus a global
   aggregate for that subset. Differs from /api/app-pair-leaders in
   two ways: (a) leaders returns top-10 per subset across ALL subsets;
   this returns ALL pairs for ONE subset; (b) leaders requires 3 graded
   samples per pair, this includes every pair with ≥1 signal so the
   user can see the full distribution.
